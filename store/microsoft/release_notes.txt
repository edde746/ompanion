ompanion 2.2.1 fixes the app with omp 18.21 and later, up to omp 19.1.1, which it now installs on a machine that lacks omp. It still works with omp 18.3.1 and later.

Fixed: with omp 18.21.0 or later, the ask tool's questions never reached the app and the agent went on without an answer; they show in the chat again. A session that sat idle for the idle-exit time stops cleanly again instead of ending with an error. With omp 19, tool cards, approvals and the Agent Hub show what each tool call is for again: the app turns omp's Intent Tracing back on while the setting is unset. Switching from a session with a goal to one without turns the goal tool off. The notification of a run whose retry failed before it started names that failure.

Changed: the app installs omp 19.1.1 on a machine that lacks omp (was 18.16.0).
