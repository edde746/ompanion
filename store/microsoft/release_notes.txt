ompanion 2.1.0 answers omp's form questions in the chat, opens an agent page's pictures in a zoomable image viewer, and uses far less data to follow a session. It works with omp 18.3.1 and later and installs omp 18.16.0 on a machine that lacks it.

New: from omp 18.18.3 the ask tool can ask with one form, and the chat shows the whole form in place, with choices, menus, text fields, tables and pictures; Submit checks your answers and names the problem under each field. Single-choice and multiple-choice questions look apart. A click on a picture in an agent page opens it in the image viewer, which now zooms: a zoom bar, double click for the image's pixels, and the +, - and 0 keys. When the interface hits an error it cannot recover from, it says so with Copy details and Reload.

Changed: a running session's log arrives compressed, 1.3 MB instead of 4.8 MB on a first open of a busy session.

Fixed: when the window comes back to the front, the app checks every machine's connection, so one that died meanwhile reconnects within seconds. Large sessions no longer reconnect with "channel failed" every few seconds. Mention chips sit on the text's baseline.
