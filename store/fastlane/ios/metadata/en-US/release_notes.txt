ompanion 2.2.0 previews Markdown files in the Files tab, shows omp's advisor notes as a card, and can hide projects that sat idle for a while. It works with omp 18.3.1 and later and installs omp 18.16.0 on a machine that lacks it.

New
- Files: a Markdown file opens as a preview, rendered as the chat renders replies: front matter shows as a YAML block, relative links open their files, and relative images load from the machine. The preview button switches to the source and back, keeping your edits
- Files: the toolbar's eye button hides or shows dotfiles
- Files: Open folder, in the editor's menu, browses the open file's folder
- omp's advisor notes show as a card instead of raw XML, each note with its severity (nit, concern, blocker); the card opens by itself when a note is a blocker
- Settings → Hide idle projects: Off, 7, 30 or 90 days. A project whose sessions all sat untouched that long leaves the sidebar; a row under each machine and the search still show it

Changed
- The chat no longer stutters while it scrolls during a reply in a session with many subagents

Fixed
- A link to a heading in a file opens the file instead of looking for a file named with the heading
- The interface could halt with an error when a part of the screen closed while its data changed
