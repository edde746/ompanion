ompanion 2.2.1 fixes the app with omp 18.21 and later, up to omp 19.1.1, which it now installs on a machine that lacks omp. It still works with omp 18.3.1 and later.

## Fixed

- With omp 18.21.0 or later, the ask tool's questions never reached the app: the tool failed at once and the agent went on without an answer. They show in the chat again
- With omp 18.21.0 or later, a session that sat idle for the idle-exit time ended with an error instead of stopping cleanly, and devices were not told why
- With omp 19, tool cards, approvals and the Agent Hub lost the one-line description of what each tool call is for, because omp turned it off for apps. The app turns it back on while omp's Intent Tracing setting is unset; set it to choose
- Switching from a session with a goal to one without left the goal tool on
- The notification of a run whose retry failed before it started names that failure, not only the original error

## Changed

- The app installs omp 19.1.1 on a machine that lacks omp (was 18.16.0)
