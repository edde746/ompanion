ompanion 1.2.1 works with omp 18.12 and installs omp 18.12.6 on a machine that lacks it.

## Changed

- iPhone Duo: the app fills both displays. Forms scroll above the keyboard on the outer display, the sidebar and panel backgrounds reach the screen edges, and adding a machine opens full screen when the phone is closed and as a window when it is open
- With omp 18.11.3 and later, a tool approval's notification says "Allow bash?" again, and the "Always approve" choices of omp 18.12.3 look like approvals

## Fixed

- omp installed with `bun install -g` can be attached to; before, opening a session on it failed with "unknown flag: -1"
- A session whose tools report large progress, such as an eval running many subagents, no longer keeps reconnecting
- Linux machines: sending to a session at the same moment as another device no longer fails
