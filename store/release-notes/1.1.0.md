ompanion 1.1.0 works with omp 18.6 and installs omp 18.6.3 on a machine that lacks it.

## New

- Keep a Mac awake while omp works, switched per machine on its page: a Mac that a request from your phone woke no longer falls back asleep mid-turn
- Update omp on a machine from its page
- Start a session without a project folder, or straight from a project row in the sidebar
- Mark sessions, folders and machines read from the sidebar
- A custom theme: pick every color the app draws
- Resize the sidebar and the dock by dragging their edge
- Images omp keeps in its blob store show in the chat
- Hide emails and organizations on the usage pane, for screenshots
- Linux: a Flatpak that runs omp and your shells on the host, and notifications with the app icon

## Changed

- When omp cannot use the model a session ran on, the app asks which model to continue on instead of failing to open the session
- Stream rule matches show as a note in the chat instead of a toast
- Sessions started from a device get a title, as in omp's terminal
- Faster opening: a device's first look at a long run replays a compacted log, images cross once, and progress updates collapse while omp works; long runs rotate their log on Windows machines too

## Fixed

- With omp 18.4.9 and later, live updates, goal and loop modes, notifications and idle exit work again
- A run that omp moves to a new session file (omp 18.4.9 and later) is followed there
- The queue and goal mode match omp 18.4
- A session's earlier subagents show when omp opens it
- The session you clicked last shows, whichever finishes opening first
- The ask form's "other" answer takes spaces typed on a keyboard
- macOS full screen keeps refreshing, and the send arrow and icon buttons draw in the right colors
