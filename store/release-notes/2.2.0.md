ompanion 2.2.0 previews Markdown files in the Files tab, shows omp's advisor notes as a card, and can hide projects that sat idle for a while. It works with omp 18.3.1 and later and installs omp 18.16.0 on a machine that lacks it.

## New

- Files: a Markdown file opens as a preview, rendered as the chat renders replies: a hard-wrapped file reads as prose, front matter shows as a YAML block, relative links open their files in the Files tab, and relative images load from the machine. The preview button switches to the source and back, keeping your edits and undo; a `file.md:12` link opens the source at that line
- Files: the toolbar's eye button hides or shows dotfiles, and a folder that holds only dotfiles says how many it hides
- Files: Open folder, in the editor's menu, browses the open file's folder
- omp's advisor notes show as a card instead of raw XML: the count of notes and blockers, then each note with its severity (nit, concern, blocker), the turn it is about (`T-2`) and the advisor that wrote it. The card opens by itself when a note is a blocker or the notes are short
- Settings → Hide idle projects: Off, 7, 30 or 90 days. A project whose sessions all sat untouched that long, none of them open, running or unread, leaves the sidebar; "Show N idle projects" under each machine lists them again, and the search still finds them

## Changed

- The chat no longer stutters while it scrolls during a reply in a session with many subagents: the Agent Hub draws only the tiles in view. In one session with 1,718 subagents, frames over 20 ms in 600 scroll steps fell from 231–288 to 12

## Fixed

- A link to a heading in a file (`docs/api.md#setup`) opens the file instead of looking for a file named with the heading
- The interface could halt with "Stale read from <Show>." when a part of the screen closed while its data changed
